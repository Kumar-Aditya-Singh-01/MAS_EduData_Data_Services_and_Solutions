# MAS EduData: GitHub Pages website

A responsive static site (navy and teal brand) with services, selected work, team and contact sections.

## Files
- `index.html`: content and sections
- `dashboards.html`: eight interactive sample dashboards (filters, drill-down, sortable tables, CSV export, print) using fictional data; logic is in `dash.js`
- `styles.css`: responsive styling
- `script.js`: mobile menu, footer year and email enquiry form (business email is set at the top of this file)
- `assets/mas-edudata-logo.png`: logo emblem cropped from the portfolio cover
- `assets/MAS_EduData_Company_Portfolio.pdf`: company portfolio

## Before publishing
1. Replace the logo in `assets/` with your original high-resolution file if you have one (keep the same name).
2. The portfolio PDF in `assets/` has been updated to the MAS brand with final contact details.
3. Confirm the pricing in the PDF is final.
4. All work on the site is sample work with fictional data. When you complete real client projects, add them as case studies (with the client's permission) in the Sample work section.

## Publish with GitHub Pages
1. Create a new public repository, named `MAS_EduData_Data_Services_and_Solutions` (this gives the URL below).
2. Upload everything in this folder, keeping `index.html` in the root.
3. Go to Settings > Pages, choose Deploy from a branch, select `main` and `/ (root)`, then save.
4. Your site will be at `https://kumar-aditya-singh-01.github.io/MAS_EduData_Data_Services_and_Solutions/`.

## Contact form
The form opens the visitor's email app with a prepared message (`mailto:`). It stores nothing. For direct submissions, connect a form service later and update `script.js`.

## Privacy
Use only fictional data in public demos. Never upload real student, parent, employee, fee or client records.
